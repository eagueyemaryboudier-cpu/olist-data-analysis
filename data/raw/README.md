# Données sources

Télécharger les neuf CSV du [dataset Olist sur Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), puis les décompresser ici sans modifier leurs noms.

Les fichiers sources ne sont pas redistribués dans ce dépôt. Ils appartiennent à leurs détenteurs respectifs ; consulter les conditions du dataset sur Kaggle. Les empreintes des fichiers analysés sont dans `../source_manifest.csv`.
